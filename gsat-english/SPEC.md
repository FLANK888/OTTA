# 學測英文模擬卷：出題規格與每週流程

每週產生一份全新的學測英文模擬卷。這份文件是出題者（包含每週自動執行的 Claude）要遵守的規格。

## 每週流程

1. 決定本週 id：用台灣時間的今天算 ISO 週次，格式 `YYYY-Www`，例如 `2026-W41`。
   `python3 -c "import datetime,zoneinfo;d=datetime.datetime.now(zoneinfo.ZoneInfo('Asia/Taipei')).date();y,w,_=d.isocalendar();print(f'{y}-W{w:02d}',d)"`
   如果 `exams/<id>.json` 已經存在，就不要再出題。
2. 讀 `data/manifest.js`，列出已經出過的主題（`topics`），本週所有文章都要選**不同**的主題。
3. 照下方題型與 `exams/2026-W41.json` 的 JSON 結構，寫出 `exams/<id>.json`。`title` 寫成「116 學測英文模擬卷 第 N 回」，N＝已出份數＋1。學測年度在每年 8 月換新：8 月起的試卷改成下一屆，例如 2027 年 8 月以後寫「117 學測」。
4. 執行 `python3 gsat-english/scripts/build.py`，修正所有錯誤到出現「[通過]」為止。
5. 只提交 `gsat-english/exams/<id>.json` 與 `gsat-english/data/`，commit 訊息寫 `Add GSAT English mock exam <id>`。

## 試卷結構（依 111 學年度起的學測英文題型）

| 部分 | 題型 | 題號 | 題數與配分 |
|---|---|---|---|
| 第壹部分 選擇題（62 分） | 一、詞彙題 | 1–10 | 10 題，每題 1 分 |
| | 二、綜合測驗 | 11–20 | 2 篇短文，每篇 5 個空格，每題 1 分 |
| | 三、文意選填 | 21–30 | 1 篇短文，10 個空格，選項 (A)–(J) 各用一次，每題 1 分 |
| | 四、篇章結構 | 31–34 | 1 篇短文，4 個句子空格，選項 (A)–(D)，每題 2 分 |
| | 五、閱讀測驗 | 35–46 | 3 篇文章，每篇 4 題，每題 2 分 |
| 第貳部分 混合題（10 分） | 題組 | 47–50 | 1 篇文章（可附表格），題型混合填充、多選、簡答，合計 10 分 |
| 第參部分 非選擇題（28 分） | 一、中譯英 | 1–2 | 2 句，每句 4 分 |
| | 二、英文作文 | — | 20 分，兩段式，至少 120 字 |

考試時間 100 分鐘，答錯不倒扣。

## 出題品質要求

**難度與用字**
- 以大考中心「高中英文參考詞彙表」為準。詞彙題的正解與選項以第 4–6 級為主，四個選項詞性相同；可用字形相近（tension / intention）或語意相近的誘答選項，但只能有一個正解。
- 綜合測驗混合考文法（關係詞、時態、分詞、連接詞）、轉折語、片語慣用語與單字。
- 文意選填的 10 個選項要混合名詞、動詞、形容詞、副詞或分詞，考生要能靠詞性和上下文排除。
- 篇章結構的選項要帶有承接線索（代名詞、轉折詞、舉例），每個空格只有一個合理答案。
- 閱讀測驗每篇 250–400 字。每篇 4 題涵蓋：主旨或標題、細節、字義推測、推論或作者態度、NOT/EXCEPT 題型中至少三種。
- 混合題依文章內容設計，例如從文中找字填表（注意字形變化）、多選題、用完整英文句子簡答。`type` 可用 `fill`、`multi`、`choice`、`short`。

**內容**
- 全部文章都要原創，不可抄錄或改寫歷屆試題、補習班講義或新聞原文。
- 主題要多元：科學、科技、環境、健康、心理、歷史、藝術、文化、社會議題、人物故事，加上至少一篇與台灣相關。各篇主題不可彼此重複，也不可與之前的試卷重複。
- 文中的事實（年份、人名、研究、數據）必須正確；沒把握的數字改成概略的說法（例如 a significant share），不要捏造研究或數據。
- 中譯英兩句要前後連貫，考常用句型（現在完成式、not only…but also、動名詞主詞、比較級等）。作文採兩段式，題目貼近高中生生活，附 150–200 字的參考範文。

**答案與解析**
- 單選題答案平均分布在 A–D，不可出現連續 4 題同一答案（`build.py` 會檢查）。
- 每題都附中文解析，說明正解理由，並簡短說明主要誘答選項錯在哪裡。
- 閱讀題的正解必須能在文中找到依據；誘答選項不能也是對的。
- 寫完後自己把整份試卷當考生作答一遍，確認每題只有唯一正解。

## 檔案

| 路徑 | 用途 |
|---|---|
| `exams/<id>.json` | 試卷原始檔，每週一份 |
| `scripts/build.py` | 檢查題型規格，產生 `data/` 底下的網頁資料 |
| `data/manifest.js`、`data/<id>.js` | 由 `build.py` 產生，不要手動修改 |
| `index.html` | 線上作答頁面：計時、自動計分、交卷後顯示解析 |
