# 學測英文週考

每週一份全新的學測英文模擬卷，題型與配分依照 111 學年度起的學測英文考科：選擇題 62 分、混合題 10 分、非選擇題 28 分，考試時間 100 分鐘。

## 使用方式

直接用瀏覽器打開 `index.html`：

- 上方選單可以切換週次，預設顯示最新一份。
- 點選答案卡圓圈作答。作答內容會自動存在瀏覽器裡，下次打開會接著作答。
- 「開始計時」會倒數 100 分鐘，時間到會自動交卷。
- 交卷後，選擇題與混合題 47–49 題會自動計分，並顯示每題解析。第 50 題、中譯英和作文會顯示參考答案，請自己填入自評分數，總分會即時更新。
- 用瀏覽器的列印功能（Ctrl/⌘ + P）可以印出不含答案的紙本試卷。

## 每週產生方式

每週六早上會有一個 Claude 排程依照 [`SPEC.md`](SPEC.md) 出一份新卷，寫成 `exams/<週次>.json`，用 `scripts/build.py` 檢查題型規格後提交到 `claude/gsat-english-weekly` 分支。

手動新增或修改試卷後，執行：

```bash
python3 gsat-english/scripts/build.py          # 檢查並產生 data/
python3 gsat-english/scripts/build.py --check  # 只檢查
```
